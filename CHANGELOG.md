# Changelog

Todos los cambios importantes de este proyecto se documentarán en este archivo.

El formato sigue las recomendaciones de [Keep a Changelog](https://keepachangelog.com/es/1.1.0/) y utiliza versionado semántico.

## [1.0.0] - 2026-11-23

### Added
- Función para calcular el porcentaje de impuestos.
- Función para calcular el precio final con impuestos.
- Función para calcular el total de una compra.
- Validación de precios y porcentajes negativos.
- Documentación del código mediante JSDoc.
- Pipeline de integración continua con GitHub Actions.
- Análisis estático del código mediante ESLint.
- Generación de documentación como artefacto del pipeline.
- Documentación de medidas de seguridad en SECURITY.md.

### Changed
- Mejora de la estructura y organización del proyecto.
- Renombrado de parámetros para mejorar la claridad del código.

### Fixed
- Resolución de conflictos durante la integración de ramas.
- Corrección de errores detectados por ESLint.
