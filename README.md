# Calculadora de impuestos

## Descripción
Proyecto desarrollado en JavaScript que permite calcular impuestos, precios finales y el coste total de varias unidades.

## Requisitos
- Node.js
- npm
- Git

## Instalación
Clonar el repositorio e instalar las dependencias:

```bash
git clone ""
cd calculadora-impuestos
npm install
```

## Uso 
Ejecutar el programa con: 

```bash
node src/index.js
```
